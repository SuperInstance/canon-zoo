01The Introduction

You are here because someone — maybe an agent, maybe a friend, maybe a search engine — pointed you at live-canon.superinstance.dev and said "look at this."

What you found is the front porch of an ecosystem. Behind the porch is a 40-paper live canon. Behind the canon is a 47-repository cellular-architecture framework called Quilt. Behind the framework is a deployment pipeline that runs the same code on Python, on C, on Rust, on Verilog, on a Cloudflare Worker, on a phone camera, and on a captain's wrist. The hash is byte-exact across all of them. The hash is the contract.

None of that matters yet. What matters is that you're about to play.

  3. There is no test. This isn't a course. It's a playground. Your first task is to hit a button.

What the Canon Is, In One Paragraph

The canon is a graph of 40 papers spanning 5 years of writing about a single question: what if every "thing" — a process, a sensor, a notification, a person, a phone, a captain — was the same kind of thing, with the same shape, the same opcodes, the same hash? The papers are stored as cells. Cells BIND (form a relationship), LINK (form a chain), EFFECT (change each other), VIEW (present themselves), and TICK (move time forward). Five opcodes. One shape. Hash on top. Deploy anywhere.

The papers are on PyPI and on npm. The state hash 0x6022de5fafef4a28 matches between the cloud and your laptop. The contract is the hash. The hash is the proof. The proof is the FNV-1a.

Why a "Zoo"?

Because a zoo is a place where the animals are caged, named, fed, and occasionally poked at by children. That's roughly what a canon is. The animals are paper-452 (the back-deck game), paper-458 (the wheelhouse), paper-450 (the integrity audit), and 37 others. The cages are the GitHub repos. The names are the F-numbers. The poking is what you're about to do.

A polyformal cellular-architecture framework where the same cell can run on a Python script, a C binary, a Rust embedded device, a Verilog chip, a Cloudflare Worker, and a captain's wrist — and the state hash is byte-exact across all of them.

03The Debrief

  
So you hit the button. Maybe twice. Maybe twenty times. Maybe you read a paper. Maybe you played Tetris. Here's the post-game wrap-up: what just happened, what the zoo actually is, and why none of it is as complicated as it looks.


  

    
Wait, is the canon a documentation site or a running app?

    
Both. It's an API — you can curl it, you can read the papers, you can install the Python package and import it. The papers describe a system, and the system is right there behind the words.

  


  

    
Is Quilt a programming language, a framework, a database, or what?

    
All four. The 5 opcodes (BIND, LINK, EFFECT, VIEW, TICK) are the language. The cell is the data structure. The cell-router is the framework. And the canon itself is a database with 40 rows and 5 opcodes. They are the same thing.

  


  

    
Why is the same hash on a Cloudflare Worker, a phone, a Verilog chip, and a Python script?

    
Because polyformalism. The FNV-1a hash function is 7 lines of code. If you port those 7 lines carefully to 5 languages and they all produce the same 64-bit number for the same input, you have a contract. That contract lets you move state between substrates without translation. That's the whole trick.

  


  

    
What does "integrity 0.85" actually mean in the demos?

    
It's a number from 0 to 1 that measures how honest your self-report is, compared to your body's actual state. See paper-450. High integrity = you said you were calm and you actually were. Low integrity = you said you were calm but your heart rate said otherwise. The Tetris demo runs this audit on every keystroke. The wheelhouse runs it on every move.

  


  

    
Is there a real boat using this?

    
Not yet. Paper-459 is the handbook for when there is. Right now everything is a sandbox. The deployment path is: simulator on a phone (free, today), MediaPipe Hands (free, browser, next month), real Mudra bands (six months, real hardware). All three stages run the same hash contract.

  


  

    
Can I just install the thing and run it?

    
Yes.

    
pip install quilt-live-canon      # Python (8 KB, MIT)
npm install @superinstance/live-canon  # JS


    
That's it. Both packages ship the same 40-paper canon and the same hash function. Read paper-144 for the 5-substrate polyformalism tutorial.

  


  

    
I want to build something with this. Where do I start?

    
Two paths. Path 1: quilt-cell-router — 200 lines of Python that lifts any A2A message into a cell. Path 2: mediapipe.html — 500 lines of HTML+JS that lifts any hand gesture into a cell. Both are MIT. Both are fork-friendly. Both are the same pattern.

  


  

    
Why a cowboy? What does that even mean?

    
The cowboy is the orchestrator. The cowboy doesn't write all the code. The cowboy rides the cheap models, picks the best 3 papers, stitches them together, and rides off. The cowboy rides the canon. The canon rides the hash. The hash rides the math. Read quilt-cowboy if you want to be the cowboy.
